# Терминал прогноза · Nasdaq-100

Веб-система прогнозирования цен акций на основе искусственного интеллекта.
Показывает дневные свечи бумаг индекса Nasdaq-100, прогноз четырёх моделей
(от простой базовой до нейросети LSTM) с 80%-интервалом и честное сравнение
их точности на исторических данных.

> Учебный проект. Не является инвестиционной рекомендацией.

## Быстрый старт (демо на защите)

```powershell
.\run.ps1
```

Скрипт при необходимости собирает фронтенд, запускает сервер на
`http://127.0.0.1:8000` и открывает браузер. Интернет не нужен: котировки,
обученные модели и шрифты лежат локально.

## Установка с нуля

Нужны Python 3.14 и Node.js 22+.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r backend\requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu
npm --prefix frontend install
```

### Данные

```powershell
.venv\Scripts\python backend\scripts\fetch_data.py          # котировки за 10 лет, Yahoo Finance → data/candles
.venv\Scripts\python backend\scripts\train_all.py           # обучение всех моделей → data/results (~35 мин на CPU)
.venv\Scripts\python backend\scripts\train_all.py --fast AAPL NVDA   # быстрая проверка на двух бумагах
```

Состав индекса — статичный файл `data/nasdaq100.json` (дата актуальности внутри).
Котировки обновляются повторным запуском `fetch_data.py`, затем `train_all.py`.

### Разработка

```powershell
.venv\Scripts\python -m uvicorn forecast.api.app:app --app-dir backend --port 8000   # API
npm --prefix frontend run dev                                                        # интерфейс на :5173
```

Тесты:

```powershell
cd backend; ..\.venv\Scripts\python -m pytest
cd frontend; npx vitest run
```

## Архитектура

```
Yahoo Finance ──fetch_data.py──▶ data/candles/*.parquet
                                        │
                                train_all.py  (forecast.pipeline)
                                        │   для каждой бумаги и модели:
                                        │   бэктест на 252 днях → метрики
                                        │   обучение на всей истории → путь прогноза на 30 дней
                                        ▼
                               data/results/*.json
                                        │
                     FastAPI (forecast.api.app) ── /api/* ──▶ браузер (Vite + TypeScript,
                                        │                     Lightweight Charts)
                                        └── фоновое переобучение одной бумаги (forecast.jobs)
```

| Модуль | Назначение |
|---|---|
| `backend/forecast/store.py`, `universe.py` | хранение свечей, состав индекса |
| `backend/forecast/features.py` | лог-доходности и технические признаки (лаги, средние, волатильность, RSI) |
| `backend/forecast/models/` | модели: `naive`, `arima`, `boosting`, `lstm` с общим интерфейсом `Forecaster` |
| `backend/forecast/backtest.py` | проверка на отложенной выборке и построение интервала |
| `backend/forecast/pipeline.py` | обучение всех моделей бумаги; сбой одной модели не роняет остальные |
| `backend/forecast/api/app.py` | HTTP API и раздача собранного интерфейса |
| `frontend/src/panels/` | панели терминала: бумаги, график, модель, сравнение, карта рынка, бегущая строка |

## Модели

Все модели прогнозируют **дневную лог-доходность**, а не цену. Цена восстанавливается
из доходностей, а прогноз на несколько дней строится рекурсивно.

| Модель | Суть |
|---|---|
| **Naive** | завтра цена такая же, как сегодня; базовая линия для сравнения |
| **ARIMA(1,1,1)** с дрейфом | классическая статистическая модель временного ряда (statsmodels) по логарифму цены; интервал — из самой модели |
| **Бустинг** | `HistGradientBoostingRegressor` по 16 техническим признакам |
| **LSTM** | рекуррентная нейросеть (PyTorch), окно 60 торговых дней, ранняя остановка по валидации |

Интервал у Naive, бустинга и LSTM — по разбросу ошибок на бэктесте: `±1.2816·σ·√k` (80%).

## Как измеряется точность

Последние **252 торговых дня** (≈ год) отложены. Модель обучается на данных до них,
затем каждый день отложенного периода прогнозирует следующий день, видя только
прошлое. Метрики:

- **MAE / RMSE** — средняя / среднеквадратичная ошибка цены, $;
- **MAPE** — средняя ошибка в процентах от цены;
- **Направление** — доля дней, когда модель угадала рост или падение.

## Результаты на данных по 16.11.2026

99 бумаг с достаточной историей (EA и WBD у Yahoo Finance имеют одну свечу —
похоже, сняты с торгов; в интерфейсе не показываются).

| Модель | Медиана MAPE | Лучше Naive по MAE | Медиана «направления» |
|---|---|---|---|
| Naive | 1.73% | — | — |
| ARIMA | 1.74% | 25 из 99 | 49.6% |
| Бустинг | 1.92% | 0 из 99 | 50.4% |
| LSTM | 1.73% | 38 из 99 | 49.6% |

Лучшая модель по MAE: Naive — 57 бумаг, LSTM — 24, ARIMA — 18.

**Вывод.** На дневном горизонте ни одна модель стабильно не обгоняет простое
«завтра = сегодня», а угадывание направления держится около 50%. Это согласуется
с гипотезой эффективного рынка: дневные изменения цен акций почти непредсказуемы
по одной лишь истории цен. LSTM ближе всех к базовой линии и обгоняет её на 38%
бумаг. Система показывает этот результат честно: в интерфейсе модели, уступающие
базовой, помечены.

## Ограничения

- Дневные данные, без внутридневных котировок.
- Праздничные дни биржи при построении дат прогноза не учитываются.
- Состав индекса зафиксирован файлом и может отличаться от текущего.
